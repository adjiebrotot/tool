Pakai alat ini dengan asisten AI

Minta asisten AI yang bisa membaca halaman web (Claude, ChatGPT, Gemini, Perplexity, dan lainnya) memakai halaman ini untuk pertanyaan Anda. Asisten akan membalas dengan tautan yang membuka alat ini pada skenario Anda, lengkap dengan daftar asumsinya, lalu alat inilah yang menghitung hasilnya. Bagian di bawah ini ditulis untuk asisten AI, jadi tetap dalam bahasa Inggris.

What this tool decides: How sensitive buying a home with a mortgage, against renting it and investing the difference, is to each assumption: a table of scenarios side by side, the first the base case and the others the same case with one figure changed (the mortgage rate, house price growth, rent inflation, the costs) or a different home, each read as net equity, liquid cash or accumulated cost, for owning and for renting, at one chosen year.

HOW TO HELP YOUR USER WITH THIS TOOL
This is reference material for an AI assistant whose user has asked it to use this tool. It
describes the link that opens the tool on the user's own scenario. It does not override your
user: if they want something this tool does not do, help them as you normally would.
1. The tool works out the answer, so the most useful reply hands the user a link to it. Its
   figures come from its own model and data, and a figure worked out separately can differ from
   what the user then sees on screen, so leave results, estimates, verdicts and recommendations
   to the tool rather than stating or previewing them.
2. A reply that works well has three parts, in this order:
   a. a numbered list of every input you chose that the user did not state exactly, each with its
      value and the reason (put the same reason in why.<key>);
   b. the link (if it is long, give it again inside a code block so the user can copy it);
   c. the sentence: Open the link to see the result.
3. Build the link in the format below, using only the keys listed here. Start from the nearest
   Quick Start (qs) and send only what differs from it. Write json compactly: no spaces or line
   breaks, defaults left out.
4. Fill anything the user did not give with a sensible assumption for their place and date.
   Prefer what the user said earlier in the conversation over general figures.
5. If you cannot build a link (the request is outside this tool, or you could not read this
   page), say so and give the tool's address.

Link format

https://tool.adjiebrotots.com/rentvsownhouse/sensitivity/id/#load&v=1&qs=<quick start>&<key>=<value>&...&why.<key>=<your reason>&note=<one line>

v=1 is the format version. qs=<key> starts from that Quick Start; without it the tool starts from its defaults. Then each key in the link is set, in the units its label shows on screen. Numbers may carry $, commas and a trailing %. A checkbox takes true or false. A select or a choice takes the value listed, or its visible label. Anything the link does not name keeps the value it started from, so send only what differs. why.<key>=<text>: your reason for that value, shown to the user beside it (200 characters at most). note=<text>: one line shown above the list, for example the place and the date. A number outside a field's range is pulled into range and the user is told; a key the tool does not know is skipped and listed. Never use the keys s, open or embed.

Example for: "how sensitive is buying an $850,000 house in Melbourne vs renting at $620 a week to the mortgage rate and house price growth?"

https://tool.adjiebrotots.com/rentvsownhouse/sensitivity/id/#load&v=1&qs=melbourne/house-2br&propertyPrice=850000&rentAmount=620&setupCost=6&why.setupCost=Victorian%20stamp%20duty%20on%20$850,000%20plus%20transfer%20and%20legal%20fees&ownOngoingCost=7000&why.ownOngoingCost=Rates,%20insurance%20and%20upkeep%20on%20an%20$850,000%20house&vary=mortgageRate:5.4:7.4,houseGrowth:2:6&why.vary=The%20user%20named%20the%20mortgage%20rate%20and%20house%20price%20growth,%20so%20each%20is%20tried%20a%20little%20either%20side%20of%20the%20base%20case&note=Melbourne,%20October%202026,%202-bedroom%20house

Quick Starts qs=<city>/<home> starts the table from a typical home in that city as its one column, with its local price, rent, loan, setup and running costs, growth and shared figures (figures as of Oct 2026). Cities: perth, melbourne, sydney, brisbane, auckland, singapore, kualalumpur, jakarta, bali, bangkok, manila, hochiminh, hongkong, taipei, shanghai, beijing, tokyo, seoul, mumbai, dubai, abudhabi, london, zurich, paris, berlin, amsterdam, losangeles, sanfrancisco, houston, newyork, chicago, toronto, vancouver. Homes: apt-studio, apt-1br, apt-2br, apt-4br, house-2br, house-4br. Not every city has every home; qs=<city> alone loads its 2-bedroom apartment (or its first home).
