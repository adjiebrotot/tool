The system Total Harmonic Distortion (THD) exceeds the permissible limit. The goal is to find the optimal capacitance, inductance, and resistance of a passive harmonic filter that minimises THD, subject to a maximum resistance constraint.

03

N-1 Line Contingency — Steady-State Assessment

▾
1 Objective

Determine whether removing any single line from service (an N-1 contingency) causes a bus voltage or line loading violation. This sample demonstrates two key tool features: the wildcard object query (*.ElmLne), which automatically targets every transmission line in the network without naming them individually, and Custom Calculation outputs, which classify each simulation result.

2 Assumptions
  • All transmission lines swept via wildcard: *.ElmLne
  • Monitored bus: MainBus.ElmTerm
  • Representative line monitored for overload: CriticalLine.ElmLne
  • Voltage flag: Under if bus voltage < 0.9 p.u., Over if > 1.1 p.u., OK otherwise
  • Overload flag: True if line loading > 100%
3 Input Variables

Instead of naming every line individually, the object query *.ElmLne tells the tool to find all line elements in the network at runtime. You do not need to know their names in advance — PowerFactory resolves them when the script runs.

Enabling Permutate takes this further: rather than applying the same value to all matched lines at once, the tool creates one independent control slot per line. Each slot sweeps the outserv attribute between 0 (in service) and 1 (out of service), and the brute force loop runs every combination of those on/off states. With 4 lines that is 24 = 16 load flows, covering the base case, all N-1 outages, all N-2 outages, and so on.

For a pure N-1 study, filter the exported CSV to rows where exactly one outserv column equals 1. Each of those columns is named after the corresponding line's loc_name, so the filtering logic in pandas is straightforward.

4 Output Variables

The two Scalar outputs read raw numbers straight from PowerFactory after each load flow — bus voltage in p.u. and line loading in %. They tell you the measured value but not whether it is within acceptable limits.

Custom Calculations close that gap. Each one is a small Python function that runs immediately after the load flow, receives other output (or input) variable values as arguments by name, and returns a derived result that lands as its own column in the CSV. The argument names must match the names of other defined variables exactly.

Here, voltage_flag takes bus_voltage and returns "Under", "Over", or "OK". The overload function takes line_loading and returns True or False. Both run in every iteration.

Frequently Asked Questions

▾
How do I find the API Path? ▾

The API Path points to the PowerFactory Python API folder. It is located inside a Python subfolder of your PowerFactory installation, with a sub-folder for each available Python version. For example:

C:\Program Files\DIgSILENT\PowerFactory 2024\Python\3.10\

Choose the sub-folder that matches the Python version you are using to run your script.

When should I use Permutate? ▾

Enable Permutate on an input variable when you want the script to sweep that variable across all combinations with other permutated variables (full factorial / grid search). Disable it to vary the variable independently. For example, as a Bayesian optimisation parameter. Leave it unchecked for optimisation problems; the algorithm handles the search automatically.

Pro tip: Permutate works well for binary variables. For example, in a contingency analysis the outserv parameter is either 0 (in service) or 1 (out of service). Setting Lower = 0, Upper = 1, Step = 1 with Permutate enabled keeps the combination count manageable while covering all switching states.
What does each Study Type do? ▾
Study Type PF Command Use to Analyse ...
Steady State Load Flow (ldf) Steady state voltages, currents, loading, etc
Dynamic RMS RMS simulation (rms) Fault response, generator dynamics, inverter dynamics, etc
Dynamic EMT EMT simulation (emt) Switching transients, power electronics, detailed waveforms, etc
Harmonic Harmonic load flow (hdf) Total harmonic distortion (THD), individual harmonics, etc
Python File vs. Notebook — which should I use? ▾

Python File (.py): Best for production use, scheduled runs, or when you want to import the script as a module. Run from the terminal or your IDE.

Notebook (.ipynb): Best for exploratory work, step-by-step debugging, or when you want inline plots and tables alongside the code. Open in Jupyter.
