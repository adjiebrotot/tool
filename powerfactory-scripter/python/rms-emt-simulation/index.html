RMS and EMT simulations in PowerFactory with Python: batch runs and plots

A dynamic simulation in Python is two commands: ComInc computes the initial conditions and ComSim runs to tstop. Record variables in a results object with ElmRes.AddVariable and read the curves back with FindColumn and GetValue. On the 39-bus example, four runs of one fault cleared after 0.10 to 0.25 s show the critical clearing time lies between 0.20 and 0.25 s.

What RMS and EMT simulations are

Both are time-domain simulations run by the same two commands, and differ in what they model:

  • RMS (iopt_sim = "rms") solves the network as phasors at the fundamental frequency, with time steps of milliseconds. It is the tool for electromechanical behaviour over seconds to minutes: rotor angle stability, frequency after a trip, voltage recovery, controller tuning.
  • EMT (iopt_sim = "ins", instantaneous values) solves the instantaneous voltages and currents of every phase, with time steps of microseconds. It shows switching transients, fault waveforms with DC offset, harmonics and fast converter control.

In both, ComInc computes the initial conditions from a load flow, the study case's events (EvtShc, EvtSwitch and others in the event list IntEvt) disturb the system, and ComSim runs it to the stop time. What is recorded goes to a results object, ElmRes. A batch is a loop around them: one run per clearing time, fault location, dispatch or setting.

The method

  1. Activate a study case with dynamic models, and the events you need (here, the case's own fault at Bus 31 and its clearing).
  2. Make a results object in the study case and add what to record: res.AddVariable(obj, "c:firel") for a rotor angle, "m:fehz" for a busbar frequency, "m:u:A" for an EMT phase voltage. Point ComInc's p_resvar to it.
  3. Set the simulation: iopt_sim "rms" or "ins" on ComInc, tstop on ComSim, in seconds after app.SetAttributeModeInternal(1).
  4. For each run, change what the batch varies (the clearing event's time), run ComInc (it must return 0) and then ComSim. sim.GetSimulationTime() below tstop means the run stopped early.
  5. Read the curves: res.Load(), FindColumn(obj, variable), GetValue(row, column) (column -1 is time), then res.Release().
  6. Put the case back (settings, event times, p_resvar), reset the calculation, delete the results object, and plot.

The RMS batch script

rms_batch.py

"""RMS simulations in PowerFactory with Python: run one fault with several clearing times,
record the rotor angle of every generator, and plot all the runs on one graph.

Runs on the "39 Bus New England System" example project that comes with PowerFactory 2024.
"""
import csv
import sys

sys.path.append(r"C:\Program Files\DIgSILENT\PowerFactory 2024\Python\3.12")
import powerfactory

PROJECT = "39 Bus New England System"
STUDY_CASE = "2.3 Simulation Fault Bus 31 Stable"   # a bolted fault at Bus 31 at 0 s
CLEARING_TIMES = [0.10, 0.15, 0.20, 0.25]           # s
T_STOP = 5.0                                         # s

app = powerfactory.GetApplicationExt()               # inside PowerFactory: powerfactory.GetApplication()
app.ActivateProject(PROJECT)
case = app.GetProjectFolder("study").GetContents(STUDY_CASE + ".IntCase")[0]
case.Activate()

inc = app.GetFromStudyCase("ComInc")                 # initial conditions
sim = app.GetFromStudyCase("ComSim")                 # run simulation
clearing = inc.GetAttribute("p_event").GetContents("Short-Circuit Clearance.EvtShc")[0]
gens = app.GetCalcRelevantObjects("*.ElmSym")

# A results object of our own that records the rotor angle of every generator.
res = case.CreateObject("ElmRes", "Rotor angles")
for g in gens:
    res.AddVariable(g, "c:firel")                    # rotor angle to the reference machine, deg

app.SetAttributeModeInternal(1)                      # times in seconds, whatever the project shows
saved = (inc.GetAttribute("p_resvar"), inc.GetAttribute("iopt_sim"), sim.GetAttribute("tstop"), clearing.GetAttribute("time"))
inc.SetAttribute("p_resvar", res)
inc.SetAttribute("iopt_sim", "rms")                  # "ins" runs an EMT simulation instead
sim.SetAttribute("tstop", T_STOP)

runs = []
try:
    for tc in CLEARING_TIMES:
        clearing.SetAttribute("time", tc)            # move the case's own clearing event
        if inc.Execute() != 0:
            raise SystemExit("The initial conditions failed")
        sim.Execute()
        reached = sim.GetSimulationTime()            # less than T_STOP when the run stopped early

        res.Load()
        cols = [res.FindColumn(g, "c:firel") for g in gens]
        t, spread = [], []
        for row in range(res.GetNumberOfRows()):
            t.append(res.GetValue(row, -1)[1])       # column -1 is the time
            angles = [res.GetValue(row, c)[1] for c in cols]
            spread.append(max(angles) - min(angles))
        res.Release()
        runs.append({"Clearing time (s)": tc, "Peak spread (deg)": max(spread), "Reached (s)": reached,
                     "Stable": max(spread) < 180 and reached >= T_STOP - 1e-6, "t": t, "spread": spread})
finally:
    inc.SetAttribute("p_resvar", saved[0])           # put the case back as it was
    inc.SetAttribute("iopt_sim", saved[1])
    sim.SetAttribute("tstop", saved[2])
    clearing.SetAttribute("time", saved[3])
    app.SetAttributeModeInternal(0)
    app.ResetCalculation()
    res.Delete()

for r in runs:
    print(f"Cleared after {r['Clearing time (s)']:.2f} s: peak spread {r['Peak spread (deg)']:7.1f} deg, "
          f"{'stable' if r['Stable'] else 'loses synchronism'}")

with open("rms_runs.csv", "w", newline="") as f:
    out = csv.writer(f)
    out.writerow(["Clearing time (s)", "Peak spread (deg)", "Stable"])
    out.writerows([r["Clearing time (s)"], r["Peak spread (deg)"], r["Stable"]] for r in runs)

# One graph for all runs, in the Adjie Brotools colours (blue, gold, teal, rose).
import matplotlib
matplotlib.use("Agg")
import matplotlib.pyplot as plt

fig, ax = plt.subplots(figsize=(9, 4.8))
for r, colour in zip(runs, ["#3A71C8", "#B45309", "#1F7F63", "#C46A7E"]):
    ax.plot(r["t"], r["spread"], color=colour, lw=2, label=f"Cleared after {r['Clearing time (s)']:.2f} s")
ax.axhline(180, color="#E66A6A", ls="--", lw=1.2)
ax.set(xlabel="Time (s)", ylabel="Rotor angle spread (deg)", xlim=(0, T_STOP), ylim=(0, 400))
ax.grid(color="#DCE3F0")
ax.spines[["top", "right"]].set_visible(False)
ax.legend(frameon=False, loc="upper right")
fig.savefig("rotor_angle_spread.png", dpi=150, bbox_inches="tight")

Result: four clearing times on the 39-bus example

The bolted fault at Bus 31 (the terminal of generator G 02) is cleared after 0.10, 0.15, 0.20 and 0.25 s. The rotor angle spread is the largest minus the smallest rotor angle of the ten generators. Cleared after up to 0.20 s, the swing peaks at 131.8 degrees and dies away; cleared after 0.25 s, the spread runs up to 359 degrees, where the angle wraps round: a pole slip. The example's own study cases put the critical clearing time between 0.21 s (stable) and 0.23 s (unstable).

An EMT run

The same API runs an EMT simulation: set iopt_sim to "ins" and record instantaneous phase quantities. This runs the 39-bus example's own EMT case (a two-phase fault at Bus 03 at 0.2 s, three breakers opening at 0.3 s) for 0.5 s and reads the three phase voltages of Bus 03: 50013 samples, 0.000010 s apart, in 23 s.

emt_run.py

"""EMT simulation in PowerFactory with Python: run the study case's fault, record the three phase
voltages of the faulted busbar, and read the waveforms back.

Runs on the "39 Bus New England System" example project that comes with PowerFactory 2024.
"""
import sys

sys.path.append(r"C:\Program Files\DIgSILENT\PowerFactory 2024\Python\3.12")
import powerfactory

PROJECT = "39 Bus New England System"
STUDY_CASE = "4. EMT Simulation Fault Bus 03"     # a two-phase fault at Bus 03 at 0.2 s
T_STOP = 0.5                                       # s

app = powerfactory.GetApplicationExt()             # inside PowerFactory: powerfactory.GetApplication()
app.ActivateProject(PROJECT)
case = app.GetProjectFolder("study").GetContents(STUDY_CASE + ".IntCase")[0]
case.Activate()

inc = app.GetFromStudyCase("ComInc")
sim = app.GetFromStudyCase("ComSim")
bus = app.GetCalcRelevantObjects("Bus 03.ElmTerm")[0]

res = case.CreateObject("ElmRes", "EMT voltages")
for phase in "ABC":
    res.AddVariable(bus, f"m:u:{phase}")           # instantaneous phase voltage, p.u.

app.SetAttributeModeInternal(1)                    # times in seconds
saved = (inc.GetAttribute("p_resvar"), inc.GetAttribute("iopt_sim"), sim.GetAttribute("tstop"))
inc.SetAttribute("p_resvar", res)
inc.SetAttribute("iopt_sim", "ins")                # "ins": EMT (instantaneous values), "rms": RMS
sim.SetAttribute("tstop", T_STOP)
try:
    if inc.Execute() != 0:
        raise SystemExit("The initial conditions failed")
    sim.Execute()
    res.Load()
    cols = [res.FindColumn(bus, f"m:u:{p}") for p in "ABC"]
    t = [res.GetValue(row, -1)[1] for row in range(res.GetNumberOfRows())]
    wave = {p: [res.GetValue(row, c)[1] for row in range(len(t))] for p, c in zip("ABC", cols)}
    res.Release()
finally:
    inc.SetAttribute("p_resvar", saved[0])
    inc.SetAttribute("iopt_sim", saved[1])
    sim.SetAttribute("tstop", saved[2])
    app.SetAttributeModeInternal(0)
    app.ResetCalculation()
    res.Delete()

print(f"{len(t)} samples, {t[1] - t[0]:.6f} s apart; phase A peak before the fault "
      f"{max(abs(u) for u, tt in zip(wave['A'], t) if tt < 0.2):.3f} p.u.")

How the script works

  • Step 2 loops over FAULT_DURATION_VALUES (0.1, 0.15, 0.2 and 0.25 s).
  • Step 3, add_short_circuit, puts a three-phase fault at FAULT_TARGET at 1 s and its clearing (an EvtShc with i_shc 4) after the pass's duration; while the workflow's own events run, the study case's events are switched off.
  • Step 4, run_rms, makes a temporary results object, records the rotor angle spread of every ElmSym, runs ComInc and ComSim to 5 s, reads the curve with GetColumnValues and puts every setting back.
  • Step 5 checks the spread against ROTOR_ANGLE_SPREAD_HI (180 degrees); a run that stops early goes on to the check too. Step 6 adds the row, with the curve's peak from the Peak block.
  • Step 7 collects one curve per pass and draws them together as a PNG when the loop ends.

Pitfalls

  • Times are in the unit the project shows. SetAttribute("tstop", 5) means 5 ms in a project that shows milliseconds. Call app.SetAttributeModeInternal(1) to write seconds, and set it back to 0.
  • Events must be in the event list ComInc reads, inc.GetAttribute("p_event"). An event made anywhere else does nothing.
  • A fault is cleared by a second EvtShc with i_shc 4 at the clearing time. Its i_clearShc option does not clear a fault in an RMS or EMT run.
  • Run ComInc before every ComSim and check it returned 0: after a failed initialisation there is nothing valid to simulate, so record the run as failed and go on.
  • A run can stop early when a machine loses synchronism or the solution fails. Compare sim.GetSimulationTime() with tstop and keep the run as a result.
  • Unbalanced faults need an unbalanced run. A balanced RMS simulation applies a single-phase fault as a three-phase one; set iopt_net on ComInc to "rst".
  • Reading is slow value by value. GetValue is fine for a few curves; for many, GetColumnValues into an IntVec reads a whole column at once.
  • Clean up: ResetCalculation(), then delete the results object you made, and put p_resvar and the event times back.

Questions

How do I run an RMS simulation in PowerFactory with Python?

Get ComInc and ComSim with app.GetFromStudyCase, set iopt_sim to "rms" on ComInc and tstop on ComSim, then call inc.Execute() and sim.Execute().

How do I run an EMT simulation in PowerFactory with Python?

The same two commands with iopt_sim set to "ins" (instantaneous values); record phase variables such as m:u:A.

How do I read simulation results in Python?

Add variables to an ElmRes with AddVariable before the run. After it, call Load(), find a column with FindColumn(obj, variable), read rows with GetValue(row, column) (column -1 is time) and call Release().

How do I find the critical clearing time with a script?

Run the fault with longer and longer clearing times and check the rotor angle spread, or search the edge between stable and unstable by halving the gap. The Builder's "Critical clearing time" Quick Start does the search.
