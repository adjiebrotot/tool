Short-circuit automation in PowerFactory with Python

In Python, a short-circuit calculation is the study case's ComShc command: set the method (iopt_mde = 1 for IEC 60909), the fault type (iopt_shc = "3psc") and the location (iopt_allbus = 2 for every busbar), call Execute(), then read m:Ikss, m:ip and m:Skss on each busbar.

What a short-circuit calculation gives you

A short-circuit calculation gives the current that flows into a fault, and the currents and voltages around it. The maximum currents size equipment: the breaking capacity of breakers, the peak and thermal withstand of busbars and cables, and the fault level a new connection adds to. The minimum currents check that protection still sees a fault.

PowerFactory has several methods in one command, ComShc: IEC 60909 and its German twin VDE 0102 (an equivalent voltage source at the fault with a voltage factor c, no load flow needed), ANSI (IEEE C37), and the complete method, which superimposes the fault on a load flow. The results on a faulted busbar include the initial symmetrical current m:Ikss (Ik"), the peak current m:ip and the initial short-circuit power m:Skss (Sk" = √3 Un Ik").

The method

  1. Activate the study case whose grids and operating state you want faulted.
  2. Get the command with app.GetFromStudyCase("ComShc") and keep its settings to put back.
  3. Choose the method and the fault: iopt_mde 1 for IEC 60909; iopt_shc "3psc" three-phase, "2psc" two-phase, "spgf" single-phase to ground, "2pgf" two-phase to ground; iopt_cur 0 for maximum or 1 for minimum currents.
  4. Choose where: iopt_allbus = 2 faults every busbar in turn in one run, or iopt_allbus = 0 with shcobj set to one busbar or line.
  5. Run with Execute() (0 means it worked) and read m:Ikss, m:ip and m:Skss on each faulted ElmTerm.
  6. Save the rows to CSV, and put the command's settings back.

The script

short_circuit.py

"""Short circuit in PowerFactory with Python: an IEC 60909 three-phase fault at every busbar, with
the initial, peak and power values of each saved to CSV.

Runs on the "Nine-bus System" example project that comes with PowerFactory 2024.
"""
import csv
import sys

sys.path.append(r"C:\Program Files\DIgSILENT\PowerFactory 2024\Python\3.12")
import powerfactory

PROJECT = "Nine-bus System"
STUDY_CASE = "01- Load Flow"

app = powerfactory.GetApplicationExt()          # inside PowerFactory: powerfactory.GetApplication()
app.ActivateProject(PROJECT)
app.GetProjectFolder("study").GetContents(STUDY_CASE + ".IntCase")[0].Activate()

shc = app.GetFromStudyCase("ComShc")
saved = {a: shc.GetAttribute(a) for a in ("iopt_mde", "iopt_shc", "iopt_cur", "iopt_allbus")}
shc.SetAttribute("iopt_mde", 1)         # method: 0 VDE 0102, 1 IEC 60909, 2 ANSI, 3 complete
shc.SetAttribute("iopt_shc", "3psc")    # fault: 3psc three-phase, 2psc two-phase, spgf single-phase to ground
shc.SetAttribute("iopt_cur", 0)         # 0 maximum, 1 minimum short-circuit currents
shc.SetAttribute("iopt_allbus", 2)      # 2 a fault at every busbar, one at a time
try:
    if shc.Execute() != 0:
        raise SystemExit("The short-circuit calculation failed")
    rows = [{"Busbar": b.loc_name, "Nominal (kV)": round(b.uknom, 2),
             "Ikss (kA)": b.GetAttribute("m:Ikss"),      # initial symmetrical short-circuit current
             "ip (kA)": b.GetAttribute("m:ip"),          # peak short-circuit current
             "Skss (MVA)": b.GetAttribute("m:Skss")}     # initial short-circuit power
            for b in app.GetCalcRelevantObjects("*.ElmTerm")]
finally:
    for a, v in saved.items():                  # leave the command as it was
        shc.SetAttribute(a, v)

for r in sorted(rows, key=lambda r: -r["Ikss (kA)"]):
    print(f"{r['Busbar']:6} {r['Nominal (kV)']:6.1f} kV  Ikss {r['Ikss (kA)']:6.2f} kA  ip {r['ip (kA)']:6.2f} kA")

with open("short_circuit_results.csv", "w", newline="") as f:
    out = csv.DictWriter(f, fieldnames=list(rows[0]))
    out.writeheader()
    out.writerows(rows)

How the script works

  • Step 2 finds every busbar in service that matches BUSBAR_EL (* for all) and loops over them.
  • Step 3, run_short_circuit, sets ComShc for this run only (IEC 60909, three-phase, maximum, the fault at this pass's busbar through shcobj) and puts the settings back.
  • Steps 4 and 5 read m:Ikss in kA and m:Skss in MVA at the faulted busbar; step 6 adds the row.
  • After the loop, two "Table column" blocks pull the busbar names and the currents out of the table, and "Draw 2D graph" saves the bar chart as a PNG in the Adjie Brotools style.

Pitfalls

  • Set the method every time. The Nine-bus example's short-circuit command is set to VDE 0102 (iopt_mde 0). A script that does not set iopt_mde gets whatever the study case holds.
  • iopt_shc is text, not a number: "3psc", "2psc", "spgf", "2pgf".
  • With one fault location, another busbar's m:Ikss is not its fault level. Only the faulted busbar carries its own fault current. Use iopt_allbus = 2, or loop and fault each busbar, to get a fault level everywhere.
  • Maximum and minimum currents answer different questions. Maximum (iopt_cur 0) rates equipment; minimum (1) checks protection reaches. Run both when you need both.
  • ANSI gives other result names than IEC 60909, so a script written for one method may raise AttributeError with the other. Check the busbar's short-circuit results in the ElmTerm reference.
  • Put the command's settings back (the script does it in finally), or the next person to open the study case gets your method and fault type.

Questions

How do I run a short circuit in PowerFactory with Python?

Get the command with app.GetFromStudyCase("ComShc"), set iopt_mde, iopt_shc, iopt_cur and the location (iopt_allbus or shcobj), then call Execute(). It returns 0 when it worked.

How do I get the fault level at every busbar?

Set iopt_allbus to 2 before Execute(), then read m:Ikss (kA) and m:Skss (MVA) on every ElmTerm.

What does iopt_mde mean?

The calculation method of ComShc: 0 VDE 0102, 1 IEC 60909, 2 ANSI, 3 the complete method, 4 IEC 61363.

What are Ikss, ip and Skss?

Ikss (Ik") is the initial symmetrical short-circuit current, ip the peak short-circuit current, and Skss (Sk") the initial short-circuit power, √3 Un Ik".
