What ElmTerm is

A terminal: a busbar, a junction node or an internal node. Node results are read here: voltage magnitude and angle after a load flow, fault levels after a short circuit, frequency during an RMS simulation.

Read and write ElmTerm in Python

import powerfactory

app = powerfactory.GetApplication()          # GetApplicationExt() from outside PowerFactory
app.GetFromStudyCase("ComLdf").Execute()      # results exist after a calculation

for bus in app.GetCalcRelevantObjects("*.ElmTerm"):
    u = bus.GetAttribute("m:u")                   # Voltage, Magnitude, p.u.
    ul = bus.GetAttribute("m:Ul")                 # Line-Line Voltage, Magnitude, kV
    print(bus.loc_name, u, ul)

bus = app.GetCalcRelevantObjects("*.ElmTerm")[0]
bus.SetAttribute("outserv", 1)                # take the terminal out of service
  • An input parameter is read and written with or without its e: prefix: GetAttribute("outserv") and GetAttribute("e:outserv") give the same value.
  • RMS and EMT variables change over time: record them in a results object (ElmRes) to read the whole curve. GetAttribute after a run gives the value at the last time step.
