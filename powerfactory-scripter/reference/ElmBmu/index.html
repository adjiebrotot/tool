What ElmBmu is

A virtual power plant: a group of generators dispatched together towards one active power setpoint.

Class
ElmBmu, element class
PowerFactory name
Virtual Power Plant
Attributes
122 input parameters and 11 result variables, in 2 calculations

Read and write ElmBmu in Python

import powerfactory

app = powerfactory.GetApplication()          # GetApplicationExt() from outside PowerFactory

for obj in app.GetCalcRelevantObjects("*.ElmBmu"):
    print(obj.loc_name, obj.GetAttribute("loc_name")) # Name

obj = app.GetCalcRelevantObjects("*.ElmBmu")[0]
obj.SetAttribute("loc_name", "VPP 1")         # rename it
  • An input parameter is read and written with or without its e: prefix: GetAttribute("outserv") and GetAttribute("e:outserv") give the same value.
