ElmFile attributesPowerFactory Measurement File

Every attribute of the PowerFactory Measurement File (ElmFile): 15 input parameters and 172 result variables, with units and meaning. Copy a name into GetAttribute or SetAttribute.

What ElmFile is

A measurement file: it reads a time series from a file and feeds it into a simulation as a signal.

Class
ElmFile, element class
PowerFactory name
Measurement File
Attributes
15 input parameters and 172 result variables, in 5 calculations

Read and write ElmFile in Python

import powerfactory

app = powerfactory.GetApplication()          # GetApplicationExt() from outside PowerFactory

for obj in app.GetCalcRelevantObjects("*.ElmFile"):
    print(obj.loc_name, obj.GetAttribute("loc_name")) # Name

obj = app.GetCalcRelevantObjects("*.ElmFile")[0]
obj.SetAttribute("outserv", 1)                # switch it off
  • An input parameter is read and written with or without its e: prefix: GetAttribute("outserv") and GetAttribute("e:outserv") give the same value.
  • RMS and EMT variables change over time: record them in a results object (ElmRes) to read the whole curve. GetAttribute after a run gives the value at the last time step.
