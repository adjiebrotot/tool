Read and write ElmVscmono in Python

import powerfactory

app = powerfactory.GetApplication()          # GetApplicationExt() from outside PowerFactory
app.GetFromStudyCase("ComLdf").Execute()      # results exist after a calculation

for obj in app.GetCalcRelevantObjects("*.ElmVscmono"):
    urnet_busac = obj.GetAttribute("m:urnet:busac") # Voltage, Real Part, referred to network, p.u.
    print(obj.loc_name, urnet_busac)

obj = app.GetCalcRelevantObjects("*.ElmVscmono")[0]
obj.SetAttribute("outserv", 1)                # take the converter out of service
  • A result at a terminal of the pwm converter/1 dc-connection needs the terminal in its name: m:P:busac, not m:P, which raises AttributeError.
  • An input parameter is read and written with or without its e: prefix: GetAttribute("outserv") and GetAttribute("e:outserv") give the same value.
  • RMS and EMT variables change over time: record them in a results object (ElmRes) to read the whole curve. GetAttribute after a run gives the value at the last time step.
