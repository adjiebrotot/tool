Every attribute of the PowerFactory Secondary Substation (ElmTrfstat): 40 input parameters and 81 result variables, with units and meaning. Copy a name into GetAttribute or SetAttribute.

What ElmTrfstat is

A secondary substation: an MV/LV substation with its transformer, as found along distribution feeders.

Class
ElmTrfstat, element class
PowerFactory name
Secondary Substation
Attributes
40 input parameters and 81 result variables, in 3 calculations

Read and write ElmTrfstat in Python

import powerfactory

app = powerfactory.GetApplication()          # GetApplicationExt() from outside PowerFactory

for obj in app.GetCalcRelevantObjects("*.ElmTrfstat"):
    print(obj.loc_name, obj.GetAttribute("loc_name")) # Name

obj = app.GetCalcRelevantObjects("*.ElmTrfstat")[0]
obj.SetAttribute("loc_name", "Kiosk 12")      # rename it
  • An input parameter is read and written with or without its e: prefix: GetAttribute("outserv") and GetAttribute("e:outserv") give the same value.
