Read and write ElmTr3 in Python

import powerfactory

app = powerfactory.GetApplication()          # GetApplicationExt() from outside PowerFactory
app.GetFromStudyCase("ComLdf").Execute()      # results exist after a calculation

for trafo in app.GetCalcRelevantObjects("*.ElmTr3"):
    loading = trafo.GetAttribute("c:loading")     # Maximum Loading, %
    p_bushv = trafo.GetAttribute("m:P:bushv")     # Active Power, MW
    print(trafo.loc_name, loading, p_bushv)

trafo = app.GetCalcRelevantObjects("*.ElmTr3")[0]
trafo.SetAttribute("outserv", 1)              # take the transformer out of service
  • A result at a terminal of the 3-winding transformer needs the terminal in its name: m:P:bushv, not m:P, which raises AttributeError.
  • An input parameter is read and written with or without its e: prefix: GetAttribute("outserv") and GetAttribute("e:outserv") give the same value.
  • RMS and EMT variables change over time: record them in a results object (ElmRes) to read the whole curve. GetAttribute after a run gives the value at the last time step.
