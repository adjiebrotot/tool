What EvtShc is

A short-circuit event: it applies (or clears) a fault on a terminal or a line at a set time of an RMS or EMT simulation.

Read and write EvtShc in Python

import powerfactory

app = powerfactory.GetApplication()          # GetApplicationExt() from outside PowerFactory

inc = app.GetFromStudyCase("ComInc")
events = inc.GetAttribute("p_event")          # the event list the simulation reads
bus = app.GetCalcRelevantObjects("*.ElmTerm")[0]
ev = events.CreateObject("EvtShc", "My short-circuit event")
ev.SetAttribute("p_target", bus)
app.SetAttributeModeInternal(1)               # write the time in seconds, whatever unit the project shows
ev.SetAttribute("time", 1.0)
app.SetAttributeModeInternal(0)
ev.SetAttribute("i_shc", 0)                   # 0 three-phase, 1 two-phase, 2 single-phase to ground, 3 two-phase to ground, 4 clears the fault
  • Times are written in the unit the project shows (some show milliseconds); SetAttributeModeInternal(1) makes it seconds. A fault is cleared by a second EvtShc with i_shc 4: i_clearShc does not clear it in an RMS or EMT run.
