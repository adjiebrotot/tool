What ElmTr2 is

A two-winding transformer between an HV and an LV terminal. Rating, impedance and tap changer data sit in its type (TypTr2); the element holds the tap position and the number of parallel units.

Read and write ElmTr2 in Python

import powerfactory

app = powerfactory.GetApplication()          # GetApplicationExt() from outside PowerFactory
app.GetFromStudyCase("ComLdf").Execute()      # results exist after a calculation

for trafo in app.GetCalcRelevantObjects("*.ElmTr2"):
    loading = trafo.GetAttribute("c:loading")     # Loading, %
    p_bushv = trafo.GetAttribute("m:P:bushv")     # Active Power, MW
    print(trafo.loc_name, loading, p_bushv)

trafo = app.GetCalcRelevantObjects("*.ElmTr2")[0]
trafo.SetAttribute("nntap", 2)                # move the tap to position 2
  • A result at a terminal of the 2-winding transformer needs the terminal in its name: m:P:bushv, not m:P, which raises AttributeError.
  • An input parameter is read and written with or without its e: prefix: GetAttribute("outserv") and GetAttribute("e:outserv") give the same value.
  • RMS and EMT variables change over time: record them in a results object (ElmRes) to read the whole curve. GetAttribute after a run gives the value at the last time step.
