ElmComp attributesPowerFactory Composite Model

Every attribute of the PowerFactory Composite Model (ElmComp): 13 input parameters, with units and meaning. Copy a name into GetAttribute or SetAttribute.

What ElmComp is

A composite model: the frame that wires DSL models, measurement devices and network elements together into one plant model.

Class
ElmComp, element class
PowerFactory name
Composite Model
Attributes
13 input parameters

Read and write ElmComp in Python

import powerfactory

app = powerfactory.GetApplication()          # GetApplicationExt() from outside PowerFactory

for obj in app.GetCalcRelevantObjects("*.ElmComp"):
    print(obj.loc_name, obj.GetAttribute("loc_name")) # Name

obj = app.GetCalcRelevantObjects("*.ElmComp")[0]
obj.SetAttribute("outserv", 1)                # switch the plant model off
  • An input parameter is read and written with or without its e: prefix: GetAttribute("outserv") and GetAttribute("e:outserv") give the same value.
