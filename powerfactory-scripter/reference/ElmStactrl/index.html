Every attribute of the PowerFactory Station Control (ElmStactrl): 84 input parameters and 31 result variables, with units and meaning. Copy a name into GetAttribute or SetAttribute.

What ElmStactrl is

A station controller: it shares the reactive power or voltage control of a station between several machines.

Class
ElmStactrl, element class
PowerFactory name
Station Control
Attributes
84 input parameters and 31 result variables, in 2 calculations

Read and write ElmStactrl in Python

import powerfactory

app = powerfactory.GetApplication()          # GetApplicationExt() from outside PowerFactory

for obj in app.GetCalcRelevantObjects("*.ElmStactrl"):
    print(obj.loc_name, obj.GetAttribute("loc_name")) # Name

obj = app.GetCalcRelevantObjects("*.ElmStactrl")[0]
obj.SetAttribute("outserv", 1)                # switch the controller off
  • An input parameter is read and written with or without its e: prefix: GetAttribute("outserv") and GetAttribute("e:outserv") give the same value.
