What ElmLod is

A general load. Its P and Q are set on the element; how they change with voltage and frequency is set in the load type (TypLod).

Read and write ElmLod in Python

import powerfactory

app = powerfactory.GetApplication()          # GetApplicationExt() from outside PowerFactory
app.GetFromStudyCase("ComLdf").Execute()      # results exist after a calculation

for load in app.GetCalcRelevantObjects("*.ElmLod"):
    p_bus1 = load.GetAttribute("m:P:bus1")        # Active Power, MW
    q_bus1 = load.GetAttribute("m:Q:bus1")        # Reactive Power, Mvar
    print(load.loc_name, p_bus1, q_bus1)

load = app.GetCalcRelevantObjects("*.ElmLod")[0]
load.SetAttribute("plini", 140)               # demand 140 MW
  • A result at a terminal of the general load needs the terminal in its name: m:P:bus1, not m:P, which raises AttributeError.
  • An input parameter is read and written with or without its e: prefix: GetAttribute("outserv") and GetAttribute("e:outserv") give the same value.
  • RMS and EMT variables change over time: record them in a results object (ElmRes) to read the whole curve. GetAttribute after a run gives the value at the last time step.
