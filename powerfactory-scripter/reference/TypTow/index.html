What TypTow is

A tower type: the position of each conductor and earth wire on a tower and the conductor types, from which line impedances and couplings are computed.

Read and write TypTow in Python

import powerfactory

app = powerfactory.GetApplication()          # GetApplicationExt() from outside PowerFactory

# Types live in the equipment library of the project.
types = app.GetProjectFolder("equip").GetContents("*.TypTow", 1)
for typ in types:
    print(typ.loc_name, typ.GetAttribute("frnom")) # Nominal Frequency, Hz

types[0].SetAttribute("rearth", 100)          # earth resistivity 100 Ohm*m: every element of this type changes
  • An input parameter is read and written with or without its e: prefix: GetAttribute("outserv") and GetAttribute("e:outserv") give the same value.
  • A type is shared: a change to it changes every element that uses it. Read a type value through an element with the t: prefix.
