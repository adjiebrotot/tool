What ElmFeeder is

A feeder: the radial path that starts at one cubicle, used for voltage profiles, feeder load scaling and feeder results.

Class
ElmFeeder, element class
PowerFactory name
Feeder
Attributes
69 input parameters and 196 result variables, in 3 calculations

Read and write ElmFeeder in Python

import powerfactory

app = powerfactory.GetApplication()          # GetApplicationExt() from outside PowerFactory

for obj in app.GetCalcRelevantObjects("*.ElmFeeder"):
    print(obj.loc_name, obj.GetAttribute("loc_name")) # Name

obj = app.GetCalcRelevantObjects("*.ElmFeeder")[0]
obj.SetAttribute("loc_name", "Feeder 1")      # rename the feeder
  • An input parameter is read and written with or without its e: prefix: GetAttribute("outserv") and GetAttribute("e:outserv") give the same value.
