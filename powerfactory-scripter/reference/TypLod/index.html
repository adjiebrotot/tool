Every attribute of the PowerFactory General Load Type (TypLod): 48 input parameters, with units and meaning. Copy a name into GetAttribute or SetAttribute.

What TypLod is

A general load type: how a load's P and Q change with voltage and frequency (the exponents and coefficients of its static model) and its dynamic share.

Read and write TypLod in Python

import powerfactory

app = powerfactory.GetApplication()          # GetApplicationExt() from outside PowerFactory

# Types live in the equipment library of the project.
types = app.GetProjectFolder("equip").GetContents("*.TypLod", 1)
for typ in types:
    print(typ.loc_name, typ.GetAttribute("kpu"))  # Exponent e_cP

# An element points to its type with typ_id; t: reads a type value through the element.
for load in app.GetCalcRelevantObjects("*.ElmLod"):
    print(load.loc_name, load.typ_id.loc_name, load.GetAttribute("t:kpu"))

types[0].SetAttribute("kpu", 2)               # voltage exponent e_cP of P: every element of this type changes
  • An input parameter is read and written with or without its e: prefix: GetAttribute("outserv") and GetAttribute("e:outserv") give the same value.
  • A type is shared: a change to it changes every element that uses it. Read a type value through an element with the t: prefix.
