What TypTr2 is

A 2-winding transformer type: rated power and voltages, short-circuit voltage, losses, vector group and tap changer.

Read and write TypTr2 in Python

import powerfactory

app = powerfactory.GetApplication()          # GetApplicationExt() from outside PowerFactory

# Types live in the equipment library of the project.
types = app.GetProjectFolder("equip").GetContents("*.TypTr2", 1)
for typ in types:
    print(typ.loc_name, typ.GetAttribute("strn")) # Rated Power, MVA

# An element points to its type with typ_id; t: reads a type value through the element.
for trafo in app.GetCalcRelevantObjects("*.ElmTr2"):
    print(trafo.loc_name, trafo.typ_id.loc_name, trafo.GetAttribute("t:strn"))

types[0].SetAttribute("strn", 200)            # rated power 200 MVA: every element of this type changes
  • An input parameter is read and written with or without its e: prefix: GetAttribute("outserv") and GetAttribute("e:outserv") give the same value.
  • A type is shared: a change to it changes every element that uses it. Read a type value through an element with the t: prefix.
