StaPll attributesPowerFactory PLL Phase/Frequency Measurement

Every attribute of the PowerFactory PLL Phase/Frequency Measurement (StaPll): 25 input parameters and 84 result variables, with units and meaning. Copy a name into GetAttribute or SetAttribute.

What StaPll is

A phase-locked loop (PLL) measurement device: it measures the phase angle and frequency at a terminal for dynamic models.

Class
StaPll, element class
PowerFactory name
PLL Phase/Frequency Measurement
Attributes
25 input parameters and 84 result variables, in 3 calculations

Read and write StaPll in Python

import powerfactory

app = powerfactory.GetApplication()          # GetApplicationExt() from outside PowerFactory

for obj in app.GetCalcRelevantObjects("*.StaPll"):
    print(obj.loc_name, obj.GetAttribute("loc_name")) # Name

obj = app.GetCalcRelevantObjects("*.StaPll")[0]
obj.SetAttribute("outserv", 1)                # switch it off
  • An input parameter is read and written with or without its e: prefix: GetAttribute("outserv") and GetAttribute("e:outserv") give the same value.
  • RMS and EMT variables change over time: record them in a results object (ElmRes) to read the whole curve. GetAttribute after a run gives the value at the last time step.
