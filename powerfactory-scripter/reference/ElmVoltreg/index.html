What ElmVoltreg is

A step-voltage regulator: an autotransformer with a tap changer that holds the voltage along a distribution feeder.

Read and write ElmVoltreg in Python

import powerfactory

app = powerfactory.GetApplication()          # GetApplicationExt() from outside PowerFactory
app.GetFromStudyCase("ComLdf").Execute()      # results exist after a calculation

for obj in app.GetCalcRelevantObjects("*.ElmVoltreg"):
    loading = obj.GetAttribute("c:loading")       # Loading, %
    print(obj.loc_name, loading)

obj = app.GetCalcRelevantObjects("*.ElmVoltreg")[0]
obj.SetAttribute("outserv", 1)                # take it out of service
  • A result at a terminal of the step-voltage regulator needs the terminal in its name: m:P:buss, not m:P, which raises AttributeError.
  • An input parameter is read and written with or without its e: prefix: GetAttribute("outserv") and GetAttribute("e:outserv") give the same value.
  • RMS and EMT variables change over time: record them in a results object (ElmRes) to read the whole curve. GetAttribute after a run gives the value at the last time step.
