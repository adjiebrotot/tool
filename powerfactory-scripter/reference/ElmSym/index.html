What ElmSym is

A synchronous machine, generator or motor. Reactances, time constants and inertia sit in its type (TypSym); the element holds the dispatch, the control mode and the number of parallel machines.

Read and write ElmSym in Python

import powerfactory

app = powerfactory.GetApplication()          # GetApplicationExt() from outside PowerFactory
app.GetFromStudyCase("ComLdf").Execute()      # results exist after a calculation

for gen in app.GetCalcRelevantObjects("*.ElmSym"):
    p_bus1 = gen.GetAttribute("m:P:bus1")         # Active Power, MW
    q_bus1 = gen.GetAttribute("m:Q:bus1")         # Reactive Power, Mvar
    print(gen.loc_name, p_bus1, q_bus1)

gen = app.GetCalcRelevantObjects("*.ElmSym")[0]
gen.SetAttribute("pgini", 120)                # dispatch 120 MW
  • A result at a terminal of the synchronous machine needs the terminal in its name: m:P:bus1, not m:P, which raises AttributeError.
  • An input parameter is read and written with or without its e: prefix: GetAttribute("outserv") and GetAttribute("e:outserv") give the same value.
  • RMS and EMT variables change over time: record them in a results object (ElmRes) to read the whole curve. GetAttribute after a run gives the value at the last time step.
