What TypSwitch is

A switch type: the ratings of a breaker or switch, such as rated current, breaking current and opening time.

Read and write TypSwitch in Python

import powerfactory

app = powerfactory.GetApplication()          # GetApplicationExt() from outside PowerFactory

# Types live in the equipment library of the project.
types = app.GetProjectFolder("equip").GetContents("*.TypSwitch", 1)
for typ in types:
    print(typ.loc_name, typ.GetAttribute("Inom")) # Rated Current, kA

# An element points to its type with typ_id; t: reads a type value through the element.
for breaker in app.GetCalcRelevantObjects("*.ElmCoup"):
    print(breaker.loc_name, breaker.typ_id.loc_name, breaker.GetAttribute("t:Inom"))

types[0].SetAttribute("Ibnom", 40)            # rated breaking current 40 kA: every element of this type changes
  • An input parameter is read and written with or without its e: prefix: GetAttribute("outserv") and GetAttribute("e:outserv") give the same value.
  • A type is shared: a change to it changes every element that uses it. Read a type value through an element with the t: prefix.
