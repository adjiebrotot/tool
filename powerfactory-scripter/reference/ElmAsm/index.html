Read and write ElmAsm in Python

import powerfactory

app = powerfactory.GetApplication()          # GetApplicationExt() from outside PowerFactory
app.GetFromStudyCase("ComLdf").Execute()      # results exist after a calculation

for motor in app.GetCalcRelevantObjects("*.ElmAsm"):
    p_bus1 = motor.GetAttribute("m:P:bus1")       # Active Power, MW
    q_bus1 = motor.GetAttribute("m:Q:bus1")       # Reactive Power, Mvar
    print(motor.loc_name, p_bus1, q_bus1)

motor = app.GetCalcRelevantObjects("*.ElmAsm")[0]
motor.SetAttribute("pgini", 2)                # active power 2 MW
  • A result at a terminal of the asynchronous machine needs the terminal in its name: m:P:bus1, not m:P, which raises AttributeError.
  • An input parameter is read and written with or without its e: prefix: GetAttribute("outserv") and GetAttribute("e:outserv") give the same value.
  • RMS and EMT variables change over time: record them in a results object (ElmRes) to read the whole curve. GetAttribute after a run gives the value at the last time step.
