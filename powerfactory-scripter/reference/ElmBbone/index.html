Every attribute of the PowerFactory Backbone (ElmBbone): 10 input parameters, with units and meaning. Copy a name into GetAttribute or SetAttribute.

What ElmBbone is

A backbone: the main path between feeders in a distribution network, used to study meshing and restoration.

Class
ElmBbone, element class
PowerFactory name
Backbone
Attributes
10 input parameters

Read and write ElmBbone in Python

import powerfactory

app = powerfactory.GetApplication()          # GetApplicationExt() from outside PowerFactory

for obj in app.GetCalcRelevantObjects("*.ElmBbone"):
    print(obj.loc_name, obj.GetAttribute("loc_name")) # Name

obj = app.GetCalcRelevantObjects("*.ElmBbone")[0]
obj.SetAttribute("loc_name", "Backbone 1")    # rename it
  • An input parameter is read and written with or without its e: prefix: GetAttribute("outserv") and GetAttribute("e:outserv") give the same value.
