What TypAsm is

An asynchronous machine type in its older form: ratings, impedances and the torque characteristic of an induction machine.

Read and write TypAsm in Python

import powerfactory

app = powerfactory.GetApplication()          # GetApplicationExt() from outside PowerFactory

# Types live in the equipment library of the project.
types = app.GetProjectFolder("equip").GetContents("*.TypAsm", 1)
for typ in types:
    print(typ.loc_name, typ.GetAttribute("sgn"))  # Rated Apparent Power, kVA

# An element points to its type with typ_id; t: reads a type value through the element.
for motor in app.GetCalcRelevantObjects("*.ElmAsm"):
    print(motor.loc_name, motor.typ_id.loc_name, motor.GetAttribute("t:sgn"))

types[0].SetAttribute("ugn", 6.6)             # rated voltage 6.6 kV: every element of this type changes
  • An input parameter is read and written with or without its e: prefix: GetAttribute("outserv") and GetAttribute("e:outserv") give the same value.
  • A type is shared: a change to it changes every element that uses it. Read a type value through an element with the t: prefix.
