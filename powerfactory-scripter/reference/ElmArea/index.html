Every attribute of the PowerFactory Area (ElmArea): 14 input parameters and 314 result variables, with units and meaning. Copy a name into GetAttribute or SetAttribute.

What ElmArea is

An area: a group of elements for summary results (generation, load, losses, interchange) and area-wide actions.

Class
ElmArea, element class
PowerFactory name
Area
Attributes
14 input parameters and 314 result variables, in 6 calculations

Read and write ElmArea in Python

import powerfactory

app = powerfactory.GetApplication()          # GetApplicationExt() from outside PowerFactory

for obj in app.GetCalcRelevantObjects("*.ElmArea"):
    print(obj.loc_name, obj.GetAttribute("loc_name")) # Name

obj = app.GetCalcRelevantObjects("*.ElmArea")[0]
obj.SetAttribute("loc_name", "Area North")    # rename the area
  • An input parameter is read and written with or without its e: prefix: GetAttribute("outserv") and GetAttribute("e:outserv") give the same value.
  • RMS and EMT variables change over time: record them in a results object (ElmRes) to read the whole curve. GetAttribute after a run gives the value at the last time step.
