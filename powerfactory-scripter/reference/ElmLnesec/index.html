Every attribute of the PowerFactory Line Sub-Section (ElmLnesec): 112 input parameters, with units and meaning. Copy a name into GetAttribute or SetAttribute.

What ElmLnesec is

One section of a line that is split into sections, each with its own type and length.

Class
ElmLnesec, element class
PowerFactory name
Line Sub-Section
Attributes
112 input parameters

Read and write ElmLnesec in Python

import powerfactory

app = powerfactory.GetApplication()          # GetApplicationExt() from outside PowerFactory

for obj in app.GetCalcRelevantObjects("*.ElmLnesec"):
    print(obj.loc_name, obj.GetAttribute("loc_name")) # Name

obj = app.GetCalcRelevantObjects("*.ElmLnesec")[0]
obj.SetAttribute("dline", 2.5)                # section length in km
  • An input parameter is read and written with or without its e: prefix: GetAttribute("outserv") and GetAttribute("e:outserv") give the same value.
