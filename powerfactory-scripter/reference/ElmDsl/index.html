What ElmDsl is

A DSL model: one instance of a dynamic model definition (BlkDef), such as a governor, an exciter or a plant controller, used in RMS and EMT simulations. Its parameters are a list in params, in the order of the definition.

Read and write ElmDsl in Python

import powerfactory

app = powerfactory.GetApplication()          # GetApplicationExt() from outside PowerFactory

for obj in app.GetCalcRelevantObjects("*.ElmDsl"):
    print(obj.loc_name, obj.GetAttribute("loc_name")) # Name

obj = app.GetCalcRelevantObjects("*.ElmDsl")[0]
obj.SetAttribute("outserv", 1)                # switch the model off
  • An input parameter is read and written with or without its e: prefix: GetAttribute("outserv") and GetAttribute("e:outserv") give the same value.
  • RMS and EMT variables change over time: record them in a results object (ElmRes) to read the whole curve. GetAttribute after a run gives the value at the last time step.
