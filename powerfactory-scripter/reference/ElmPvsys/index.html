What ElmPvsys is

A PV system: a photovoltaic plant and its inverter. Its power inputs are in kW and kVA, not MW.

Read and write ElmPvsys in Python

import powerfactory

app = powerfactory.GetApplication()          # GetApplicationExt() from outside PowerFactory
app.GetFromStudyCase("ComLdf").Execute()      # results exist after a calculation

for pv in app.GetCalcRelevantObjects("*.ElmPvsys"):
    p_bus1 = pv.GetAttribute("m:P:bus1")          # Active Power, MW
    q_bus1 = pv.GetAttribute("m:Q:bus1")          # Reactive Power, Mvar
    print(pv.loc_name, p_bus1, q_bus1)

pv = app.GetCalcRelevantObjects("*.ElmPvsys")[0]
pv.SetAttribute("pgini", 800)                 # dispatch 800 kW
  • A result at a terminal of the pv system needs the terminal in its name: m:P:bus1, not m:P, which raises AttributeError.
  • An input parameter is read and written with or without its e: prefix: GetAttribute("outserv") and GetAttribute("e:outserv") give the same value.
  • RMS and EMT variables change over time: record them in a results object (ElmRes) to read the whole curve. GetAttribute after a run gives the value at the last time step.
