Every attribute of the PowerFactory 3-Winding Transformer Type (TypTr3): 214 input parameters, with units and meaning. Copy a name into GetAttribute or SetAttribute.

What TypTr3 is

A 3-winding transformer type: rated powers and voltages of the three windings, short-circuit voltages between them, losses and tap changers.

Read and write TypTr3 in Python

import powerfactory

app = powerfactory.GetApplication()          # GetApplicationExt() from outside PowerFactory

# Types live in the equipment library of the project.
types = app.GetProjectFolder("equip").GetContents("*.TypTr3", 1)
for typ in types:
    print(typ.loc_name, typ.GetAttribute("strn3_h")) # HV-Side, MVA

# An element points to its type with typ_id; t: reads a type value through the element.
for trafo in app.GetCalcRelevantObjects("*.ElmTr3"):
    print(trafo.loc_name, trafo.typ_id.loc_name, trafo.GetAttribute("t:strn3_h"))

types[0].SetAttribute("strn3_h", 250)         # HV rated power 250 MVA: every element of this type changes
  • An input parameter is read and written with or without its e: prefix: GetAttribute("outserv") and GetAttribute("e:outserv") give the same value.
  • A type is shared: a change to it changes every element that uses it. Read a type value through an element with the t: prefix.
