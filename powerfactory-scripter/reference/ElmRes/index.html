What ElmRes is

A results object: it stores the variables recorded during a calculation or simulation (chosen with IntMon objects), one column per variable and one row per time step or case.

Read and write ElmRes in Python

import powerfactory

app = powerfactory.GetApplication()          # GetApplicationExt() from outside PowerFactory

case = app.GetActiveStudyCase()                # a study case with a simulation set up
inc, sim = app.GetFromStudyCase("ComInc"), app.GetFromStudyCase("ComSim")
bus = app.GetCalcRelevantObjects("*.ElmTerm")[0]

res = case.CreateObject("ElmRes", "My results")  # a results object of your own
res.AddVariable(bus, "m:fehz")                 # what to record: the busbar frequency
inc.SetAttribute("p_resvar", res)              # the simulation writes to it
inc.Execute()
sim.Execute()

res.Load()
col = res.FindColumn(bus, "m:fehz")            # -1 when it was not recorded
rows = range(res.GetNumberOfRows())
t = [res.GetValue(row, -1)[1] for row in rows] # column -1 is the time, s
f = [res.GetValue(row, col)[1] for row in rows]
res.Release()
  • An input parameter is read and written with or without its e: prefix: GetAttribute("outserv") and GetAttribute("e:outserv") give the same value.
  • RMS and EMT variables change over time: record them in a results object (ElmRes) to read the whole curve. GetAttribute after a run gives the value at the last time step.
