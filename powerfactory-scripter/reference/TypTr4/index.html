What TypTr4 is

A 4-winding transformer type: ratings, impedances, losses and tap changers of the four windings.

Read and write TypTr4 in Python

import powerfactory

app = powerfactory.GetApplication()          # GetApplicationExt() from outside PowerFactory

# Types live in the equipment library of the project.
types = app.GetProjectFolder("equip").GetContents("*.TypTr4", 1)
for typ in types:
    print(typ.loc_name, typ.GetAttribute("sn_h0")) # HV-Side, MVA

# An element points to its type with typ_id; t: reads a type value through the element.
for trafo in app.GetCalcRelevantObjects("*.ElmTr4"):
    print(trafo.loc_name, trafo.typ_id.loc_name, trafo.GetAttribute("t:sn_h0"))

types[0].SetAttribute("sn_h0", 300)           # HV rated power 300 MVA: every element of this type changes
  • An input parameter is read and written with or without its e: prefix: GetAttribute("outserv") and GetAttribute("e:outserv") give the same value.
  • A type is shared: a change to it changes every element that uses it. Read a type value through an element with the t: prefix.
