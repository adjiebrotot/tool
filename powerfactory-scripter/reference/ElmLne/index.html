What ElmLne is

An overhead line or cable between two terminals. Its impedance per km and rated current sit in the line type (TypLne) it points to through typ_id; the element holds the length, the number of parallel lines and the derating.

Read and write ElmLne in Python

import powerfactory

app = powerfactory.GetApplication()          # GetApplicationExt() from outside PowerFactory
app.GetFromStudyCase("ComLdf").Execute()      # results exist after a calculation

for line in app.GetCalcRelevantObjects("*.ElmLne"):
    loading = line.GetAttribute("c:loading")      # Loading, %
    p_bus1 = line.GetAttribute("m:P:bus1")        # Active Power, MW
    print(line.loc_name, loading, p_bus1)

line = app.GetCalcRelevantObjects("*.ElmLne")[0]
line.SetAttribute("outserv", 1)               # take the line out of service
  • A result at a terminal of the line needs the terminal in its name: m:P:bus1, not m:P, which raises AttributeError.
  • An input parameter is read and written with or without its e: prefix: GetAttribute("outserv") and GetAttribute("e:outserv") give the same value.
  • RMS and EMT variables change over time: record them in a results object (ElmRes) to read the whole curve. GetAttribute after a run gives the value at the last time step.
