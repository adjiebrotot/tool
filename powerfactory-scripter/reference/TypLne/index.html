What TypLne is

A line type: the electrical data shared by every line that uses it, per km (R', X', B'), with the rated voltage and rated current.

Read and write TypLne in Python

import powerfactory

app = powerfactory.GetApplication()          # GetApplicationExt() from outside PowerFactory

# Types live in the equipment library of the project.
types = app.GetProjectFolder("equip").GetContents("*.TypLne", 1)
for typ in types:
    print(typ.loc_name, typ.GetAttribute("uline")) # Rated Voltage, kV

# An element points to its type with typ_id; t: reads a type value through the element.
for line in app.GetCalcRelevantObjects("*.ElmLne"):
    print(line.loc_name, line.typ_id.loc_name, line.GetAttribute("t:uline"))

types[0].SetAttribute("sline", 1.2)           # rated current 1.2 kA: every element of this type changes
  • An input parameter is read and written with or without its e: prefix: GetAttribute("outserv") and GetAttribute("e:outserv") give the same value.
  • A type is shared: a change to it changes every element that uses it. Read a type value through an element with the t: prefix.
