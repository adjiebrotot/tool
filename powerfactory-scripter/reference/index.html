Results (m:, c:, n:) exist only after the calculation named in the last column has run in the active study case.

What the prefix of an attribute name means

e:
Input parameter: the data of the element. Optional when you type it: GetAttribute("dline") and GetAttribute("e:dline") are the same.
m:
Currents, voltages and powers. On a branch it names the terminal: m:P:bus1, m:P:bushv. Without it, m:P on a line raises AttributeError.
c:
Calculation parameter: a result worked out from the others, such as c:loading and c:Ploss.
n:
Bus result: the result of the terminal at one end of a branch, such as n:u:bus1.
s:
Signal: a state or model variable of an RMS or EMT simulation, such as s:speed.
b:
Basic data: values derived from the input data (read only).
t:
Type parameter read through the element: line.GetAttribute("t:uline") is the rated voltage of the line's type.
:A :B :C
Per phase, in an unbalanced calculation only: m:u:A, m:I:bus1:A (capitals; :a raises AttributeError).

Each rule above was checked on the PowerFactory 2024 engine. A name a class does not have raises AttributeError.

Read and write any attribute

import powerfactory

app = powerfactory.GetApplication()          # inside PowerFactory; GetApplicationExt() from your own Python
app.GetFromStudyCase("ComLdf").Execute()      # results need a calculation first

for line in app.GetCalcRelevantObjects("*.ElmLne"):
    print(line.loc_name, line.GetAttribute("c:loading"), line.GetAttribute("m:P:bus1"))

for bus in app.GetCalcRelevantObjects("*.ElmTerm"):
    print(bus.loc_name, bus.GetAttribute("m:u"))

load = app.GetCalcRelevantObjects("*.ElmLod")[0]
load.SetAttribute("plini", 140.0)             # input data: the next load flow uses it
