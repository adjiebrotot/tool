PowerFactory Scripter

Write DIgSILENT PowerFactory Python scripts in minutes, not days.

Open Builder

or I prefer Legacy Scripter

What it does

  • Automate many simulations at once

    Loop over contingencies, study cases, operation scenarios, variations or a range of values. One run of the script does them all and collects the results in one table.

  • Simplify PowerFactory studies

    Each study is one block that asks only for the settings it needs:

    • Load flow
    • RMS simulation
    • EMT simulation
    • Harmonic load flow

  • Common power system calculations, ready made

    Wire a simulation result into a check and get the number, per run:

    • RoCoF
    • Settling time
    • Frequency nadir

  • Optimisation and limit finding, ready made

    Optimise searches the best value of one or more settings (differential evolution, Nelder-Mead, Bayesian or a grid). Find limit halves the gap to the largest value that still passes, such as a hosting capacity or a critical clearing time.

Learn PowerFactory scripting

  • Automate PowerFactory studies with Python

    One guide per study, each with a script tested on PowerFactory's example projects and its results: getting started with the API, load flow to CSV and Excel, N-1 contingency, short circuit, hosting capacity, PV and QV curves and RMS and EMT batch runs.

  • PowerFactory attribute reference

    Every attribute name for GetAttribute and SetAttribute, with units and meaning, one page per class: ElmLne, ElmTerm, ElmTr2, ElmSym and 69 more.
