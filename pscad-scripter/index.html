PSCAD Scripter

Write PSCAD Python automation scripts in minutes, not days.

Open Builder

or read the PSCAD Python guides

What it does

  • Automate many EMT runs at once

    Loop over fault durations, parameter values, snapshots or whole cases. One run of the script does them all, reads the output channels and collects the results in one table.

  • Simplify PSCAD studies

    Each step is one block that asks only for the settings it needs, with every Master Library component in the picker:

    • Build the case
    • Run the simulation
    • Set a fault
    • Save a snapshot
    • Run a simulation set

  • EMT waveform calculations, ready made

    Wire an output channel into a check and get the number, per run:

    • RMS
    • Harmonic distortion (THD)
    • Sequence component
    • Unbalance factor
    • Overshoot and rise time
    • Damping of a ringdown

  • Optimisation and limit finding, ready made

    Optimise searches the best value of one or more settings (differential evolution, Nelder-Mead, Bayesian or a grid). Find limit halves the gap to the largest value that still passes, such as a critical clearing time.

Learn PSCAD scripting

  • Automate PSCAD studies with Python

    One guide per study, each with the method and the script the Builder writes for it: getting started with the Automation Library, build a case and run it, fault ride through and critical clearing time, parameter sweeps, harmonics and THD, snapshots and batch runs and control tuning.

  • PSCAD component reference

    Every Master Library component, one page each, with its parameters, their units, ranges and defaults, and the Python that writes to them: Three Phase Voltage Source, Timed Fault Logic, 3 Phase Breaker and 380 more.

  • The Builder, and its tour

    The canvas, the Blocks panel and one settings form per block. A guided tour walks a worked fault ride through study, and the 🧭 Tour button opens it again any time.

  • Ten Quick Starts

    A finished workflow to start from, not an empty canvas: fault ride through, harmonics and THD, critical clearing time, several cases at once, damping of a ringdown, and five more.
