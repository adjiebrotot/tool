What it does

  • Wire the study, get one Python file

    An EMT run takes as long as it takes, and a sweep of them means sitting at the machine starting the next one. Wire the study once instead: 106 blocks in nine categories, from the model and the run to the checks, the graphs and the loops. Press Download and you have one Python file that opens the case, builds it, runs every pass, reads the output channels, checks them, writes the tables, and puts back every parameter, layer state and substitution it changed.

  • Built for EMT, not bolted on

    A PSCAD case is Fortran that EMTDC compiles, so the build block hands back the compiler's own error and warning lines. A fault or a breaker has its timing written into the component already drawn in the case, because PSCAD has no event list to fill. Run once to a settled state, save a snapshot, and start every later run from it. Put cases into a simulation set and run them several at a time. The solution and plot steps are set in microseconds.

    • Build the case
    • Set a fault
    • Save a snapshot
    • Run a simulation set
    • Multiple Run sweep

  • Read the waveform, not a phasor

    An EMT run records waves, so the checks work on waves. THD comes from a DFT of the time domain result, because PSCAD has no frequency domain harmonic scan. RMS is a sliding window of one cycle or more. Sequence components and the unbalance factor are worked out from three separate phase channels, and a ringdown's damping ratio is fitted from its envelope peaks, where a negative ratio means the oscillation is growing. The numbers go into results tables, CSV or Excel, and graphs:

    • RMS of a waveform
    • Harmonic distortion (THD)
    • Sequence component
    • Unbalance factor
    • Overshoot and rise time
    • Damping of a ringdown

  • The whole Master Library, in the picker

    Choose a component from 383 Master Library definitions read out of PSCAD 5.0.0 itself, each with every parameter, its unit, its range, its default and its help text. Values are written with PSCAD's own unit suffix (2.5 [ohm]) and converted on the way in and out, so a parameter goes back the way the case had it.

Learn PSCAD scripting

  • Automate PSCAD studies with Python

    One guide per study, each showing the method and the script the Builder writes for it: getting started with the Automation Library, build a case and run it, fault ride through and critical clearing time, parameter sweeps, harmonics and THD, snapshots and batch runs and control tuning.

  • PSCAD component reference

    Every Master Library definition, one page each, with its parameters, their units, ranges and defaults, what each one means, and the Python that finds the component and writes to it. 383 definitions, read out of PSCAD 5.0.0 rather than typed in by hand.

  • The Builder, and its tour

    The canvas, the Blocks panel and one settings form per block. On a first visit the Builder offers a guided tour over a worked fault ride through study, and the 🧭 Tour button opens it again whenever you want it.

  • Ten Quick Starts

    A finished workflow to start from, rather than an empty canvas: fault ride through over fault durations, harmonics and THD from an EMT run, critical clearing time, run several cases at once, damping of a ringdown, and five more.
