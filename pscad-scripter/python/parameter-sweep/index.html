Sweep a PSCAD parameter with Python

A sweep is the simplest study there is: write a value, run, read, put it back, once for each value. PSCAD adds two ways of holding variants that a sweep can go over as well: layers, which switch whole groups of components in and out, and global substitution sets, which give every $(name) in the case a different value at once.

What a parameter sweep in PSCAD is

Every component in a PSCAD case has parameters, read and written from Python as a dictionary: comp.parameters() gives them, comp.parameters(R="12.5 [ohm]") writes one. A sweep writes one parameter over a range of values and runs the case for each, recording what an output channel did.

Two things make a sweep in PSCAD different from a hand edit. A value that carries a unit is written with it, and PSCAD keeps the unit it is given. And each write changes the case on disk when it is saved, so the script records each value it replaces and puts it back.

PSCAD's own Multiple Run component sweeps up to six variables inside one run of the executable. A Python sweep is slower to start each run, but it can change anything in the case, including what Multiple Run cannot reach: a layer, a substitution set, a component's definition, the run settings.

The method

  1. Find the component by definition and Name, and check the parameter's name and unit in the component reference.
  2. Loop over the values. Each pass opens a mark, writes the value, runs, reads, records a row, and undoes the mark.
  3. Graph the result against the swept value from the table.

One parameter over a range

resistor = px_find(app, "master:resistor", "Rload")
for r in num_range(1, 10, 1):
    mark = px_mark()
    px_set(resistor, "R", r, unit="ohm")      # written in the unit R already carries
    run = px_run(app, duration=1, step=50, plot_step=250)
    table("Sweep").add({"R (ohm)": r, "Peak": peak(run.series("Vbus"), kind="abs").value})
    px_undo(mark)
plot_table("Sweep", "R (ohm)", ["Peak"])

Every layer, one at a time

A layer is a named group of components that is enabled or disabled together, so one case can hold several network arrangements: a line in or out, a second transformer, a different filter. Going over the layers puts each one in while the others are out.

for name in each_layer(app, layer_list(app, "*"), "Enabled", "Disabled"):
    run = px_run(app, duration=2, step=50, plot_step=250)
    table("Arrangements").add({"Peak": peak(run.series("Vbus"), kind="abs").value})

Every global substitution set

A global substitution is a named value that any component parameter written as $(name) takes, and a set holds one value for each. Switching the active set changes every one of them at once, which is how one case covers several parameter sets: a weak and a strong grid, summer and winter.

for name in each_gs_set(app, [n for n in gs_sets(app) if n]):
    run = px_run(app, duration=2, step=50, plot_step=250)
    table("Sets").add({"Final value": final_value(run.series("Vbus"))})

Make the sets once in PSCAD, or load them from a CSV with gs_load. A case with no named sets has one set whose name is empty, which is why the loop leaves it out.

How the script works

  • px_find(app, "master:resistor", "", "one") wants exactly one resistor. Give a Name when the case has several; with none, the error lists the Names it found.
  • px_set(resistor, "R", value, None) writes the value in the unit R already carries and records the old one.
  • A pass that does not build or stops early is skipped with a note in the table, and the next value is tried.
  • plot_table("Sweep", "Value", ["Peak"]) draws the table's Peak column against the swept value when the loop ends.

Pitfalls

  • A unit you did not mean. PSCAD stores a written unit as given: write "2500 [mohm]" and the parameter is in mohm from then on. px_set writes in the unit the parameter already carries, converting from the one you name.
  • A value read as a plain number loses its unit. A unit-carrying value comes back as a number whose unit is only in its text. Read it as text first, or use px_get with a unit.
  • A Choice written as its words. A Choice takes its symbol, the capitals in the reference, such as "YES" or "RR_L", not the words in the dialog.
  • A component that is in the case twice. find_all gives every instance, on every page and inside every module. Name the one to change, or the sweep writes on all of them.
  • Enabling a component needs PSCAD 5.0.2. Component.enabled is not there on 5.0.0; enable() and disable() are, which is what the runtime uses.

Questions

How do I change a component parameter in PSCAD from Python?

Find the component with project.find_all("master:resistor") (or by its Name), then call comp.parameters(R="12.5 [ohm]"). comp.parameters() with no arguments gives every parameter and its current value.

What is the difference between a Python sweep and Multiple Run?

Multiple Run steps up to six variables inside the case, in one go of the executable. A Python sweep starts a run per value and can change anything in the case between runs, including layers, substitution sets and the run settings.

How do I switch layers in PSCAD from a script?

Set the layer's state on the project, enabled or disabled, then run. The Builder's runtime does it with layer_set(app, name, "Enabled") and puts every layer back the way it found it at the end.
