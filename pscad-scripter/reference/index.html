PSCAD component reference

Every parameter of every component in PSCAD's Master Library, read out of PSCAD 5.0.0 itself: 345 definitions and 8,919 parameters, each with its unit, default, range and meaning, and the symbol each Choice is written as from a script.

PSCAD has no event list: a fault or a switching is a component drawn in the case, and a script times it by writing that component's parameters. The Three Phase Fault takes its timing from the Timed Fault Logic wired to it, which is why the timing is on master:tfaultn.

How a definition and a parameter are named

Definition
Namespace first, then the name, as PSCAD writes it: master:resistor, master:xfmr-3p2w. A component defined in the case itself has the case's own namespace.
Parameter
The short name in the first column, letter case included: R, RON, Vm. The description is what the component's dialog shows.
Unit
A number that carries a unit is written with it, "0.05 [ohm]", and PSCAD keeps the unit you give rather than converting it.
Choice
Written as its symbol: "YES", "BEHIND_SOURCE_IMPEDANCE". The words in the dialog are not accepted.
Used when
A parameter that only counts in some settings of another one, as the dialog shows or hides it.

Read and write any parameter

import mhi.pscad

pscad = mhi.pscad.connect()                # the PSCAD that is open; launch() starts one
project = pscad.project("my_case")         # a case loaded in the workspace

for r in project.find_all("master:resistor"):
    print(str(r.parameters()["R"]))         # its text carries the unit

flt = project.find_all("master:tfaultn")[0]
flt.parameters(TF="1.0 [s]", DF="0.12 [s]")  # fault at 1 s for 120 ms

project.run()                              # build if needed, then run the EMT simulation
