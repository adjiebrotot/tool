What Permanent Magnet Machine is

Permanent Magnet Machine is a Master Library definition in the Machines group of PSCAD 5.0.0. Permanent Magnet Synchronous Machine. Its 20 parameters are listed below as PSCAD itself reports them, with the unit, range and default of each.

Read and write Permanent Magnet Machine in Python

import mhi.pscad

pscad = mhi.pscad.connect()                # launch() starts a new PSCAD instead
project = pscad.project("mycase")

# find_all takes the definition exactly: no wildcard, and the namespace is not optional.
for comp in project.find_all("master:pm_machine"):
    print(comp.name, comp.parameters())

comp = project.find_all("master:pm_machine")[0]
comp.parameters(MVA="0.003 [MVA]", VRAT="0.2 [kV]", F="60 [Hz]")
print(comp.parameters()["MVA"])
  • A value carries its unit in the text: "250 [MVA]". PSCAD keeps the unit you write rather than converting it, so "2500 [mohm]" stays in milliohms and reads back that way.
  • A parameter read back is a subclass of float whose unit lives only in its text, so read it as text first if you need the unit.
  • The case has to be built again after a parameter changes, and project.build() reports the compiler's own lines.
