What Frequency Dependent (Phase) Model is

Frequency Dependent (Phase) Model is a Master Library definition in the Lines and cables group of PSCAD 5.0.0. Its 26 parameters are listed below as PSCAD itself reports them, with the unit, range and default of each.

Read and write Frequency Dependent (Phase) Model in Python

import mhi.pscad

pscad = mhi.pscad.connect()                # launch() starts a new PSCAD instead
project = pscad.project("mycase")

# find_all takes the definition exactly: no wildcard, and the namespace is not optional.
for comp in project.find_all("master:Line_FrePhase_Options"):
    print(comp.name, comp.parameters())

comp = project.find_all("master:Line_FrePhase_Options")[0]
comp.parameters(FS="0.01 [Hz]", FE="1000000 [Hz]", YMaxP=20)
print(comp.parameters()["FS"])
  • A value carries its unit in the text: "250 [MVA]". PSCAD keeps the unit you write rather than converting it, so "2500 [mohm]" stays in milliohms and reads back that way.
  • A parameter read back is a subclass of float whose unit lives only in its text, so read it as text first if you need the unit.
  • A parameter with a condition in the last column is only used while that condition holds. Writing it otherwise is accepted and ignored by the solution.
  • The case has to be built again after a parameter changes, and project.build() reports the compiler's own lines.

shntcabmho/mReal1E-100 to 1000000001.0E-9Cable Shunt Conductance (obsolete)This value is important in order to obtain a stable time domain simulation (i.e. it improves passivity at low frequencies) and also helps to improve the behaviour of the rational function at low frequencies. The shunt conductance should be a very small value and will not affect the high frequency behaviour of time domain simulations.
