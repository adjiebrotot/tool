master:derivative parametersPSCAD Derivative

Every parameter of the PSCAD Derivative (master:derivative): 4 names, with the unit, the default and the meaning PSCAD gives each one. Copy a name into parameters().

What master:derivative is

Derivative (Derivative with a time constant), a component of PSCAD's Master Library, filed under control blocks.

Definition
master:derivative
PSCAD name
Derivative
Category
Control blocks
Parameters
4, in 1 group; 1 carry a unit

Read and write master:derivative in Python

import mhi.pscad

pscad = mhi.pscad.connect()              # the PSCAD that is open; launch() starts one
project = pscad.project("my_case")       # a case loaded in the workspace

for comp in project.find_all("master:derivative"):   # the exact definition, namespace first
    params = comp.parameters()           # every parameter, as PSCAD holds it
    print(str(params["T"]))              # Time Constant, in s

comp = project.find_all("master:derivative")[0]
comp.parameters(T="0.002 [s]")           # a value that carries a unit is written with it
  • A parameter is named exactly as in the table, letter case included: parameters() gives every one of them in a dictionary, and a name the component does not have is refused.
  • A value that carries a unit comes back as a number whose unit is only in its text, so read it as text first (str(...)) or the unit is lost. PSCAD keeps a written unit as it is given: "2500 [mohm]" stays in mohm.
  • A Choice is read and written as its symbol (the capitals in "Written as"), not as the words PSCAD shows in the dialog.
  • find_all() takes the exact definition only. A wildcard or a bare name without master: comes back empty; the Builder's px_find walks the pages for those.

The Builder's runtime does the same with the unit handled for you: px_get(comp, "T") and px_set(...), which also records the old value so the case is put back at the end. Getting started shows them.
