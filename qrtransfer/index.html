How it works

No radio, no network

The only channel is light from one screen into one camera. Nothing is uploaded, because there is nowhere to upload to. That makes it usable on air-gapped machines and locked-down laptops.

The receiver cannot talk back

So the sender never stops. After the plain frames it keeps minting fresh repair frames, each one a combination of blocks. Any sufficient number of frames, in any order, rebuilds the file.

Every frame is checked twice

Each frame carries its own CRC-32, so a smeared or half-captured code is thrown away rather than trusted. The finished file is checked again against a checksum of the original.

Sized for small files

Expect roughly 6 to 10 KB per second. Keys, configs, documents, and photos are comfortable. Videos are not.
