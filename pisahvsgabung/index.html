Pisah Harta (K/0 + TK/0): Each spouse files their own SPT. Husband uses PTKP K/0, wife uses PTKP TK/0. Each has their own set of brackets.

Gabung Harta (K/I/0): Combined income, one SPT. Uses PTKP K/I/0. One set of brackets for all the income.
